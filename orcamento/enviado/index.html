O pedido foi para o comercial com o que você informou sobre o material. Se faltar algum dado para orçar, entramos em contato pelo WhatsApp que você deixou.

  1. Conferência do pedido. O comercial verifica se a lista de material, ou a altura e a área informadas, são suficientes para orçar.
  2. Contato, se faltar informação. Falamos pelo WhatsApp para completar o que faltar. É a etapa mais rápida quando você já tem a lista.
  3. Orçamento. Material, montagem e transporte saem separados, para você comparar cenários.
